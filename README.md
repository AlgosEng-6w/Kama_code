## 📖 Introduction

This repository documents my learning journey through the **代码随想录** algorithm training camp.

It covers core knowledge points of data structures and algorithms, ranging from basic arrays to complex dynamic programming and graph theory.

---

## 🗺️ Roadmap

Organized by the following categories:

### 1. Basic Data Structures
- **Array**: Binary search, two pointers, sliding window, etc.
- **Linked List**: Dummy head node, fast/slow pointers, reverse linked list.
- **Hash Table**: Map, Set, hash collision handling.
- **String**: KMP algorithm, string reversal, replace spaces.
- **Stack & Queue**: Monotonic stack, implement queue with stack, sliding window maximum.

### 2. Advanced Algorithms & Techniques
- **Two Pointers**: Left-right pointers, fast-slow pointers.
- **Binary Tree**: Recursive traversal, iterative traversal, level-order traversal, BST.
- **Backtracking**: Combinations, permutations, subsets, N-Queens problem.
- **Greedy Algorithm**: Derive global optimum from local optimum.
- **Dynamic Programming**: Knapsack problems, subsequence problems, stock problems.
- **Monotonic Stack**: Find next greater/smaller element.
- **Graph Theory**: DFS, BFS, shortest path algorithms.
